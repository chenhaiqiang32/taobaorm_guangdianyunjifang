🎯 项目概述

电视台三维系统是一个基于Three.js开发的Web3D可视化平台，主要用于电视台机房的实时监控和三维展示。系统支持室内外场景切换、设备监控、天气系统等功能。

主要特性

  • 🏢 三维场景渲染：支持室内外建筑模型加载和渲染
  • 🌤️ 天气系统：支持多种天气效果和日夜切换
  • 📡 WebSocket通信：实时数据更新和状态同步
  • 🎮 交互控制：支持相机控制、场景漫游等交互功能
  • 📱 响应式设计：适配不同屏幕尺寸

🚀 安装与使用

环境要求

  • Node.js >= 16.0.0
  • npm >= 8.0.0
  • 现代浏览器（支持WebGL）

安装步骤

# 1. 克隆项目 git clone [项目地址] cd web3d # 2. 安装依赖 npm install # 3. 启动开发服务器 npm run dev # 4. 构建生产版本 npm run build

可用脚本

命令 描述
npm run dev 启动开发服务器（支持热重载）
npm run build 构建生产版本到docs目录
npm run preview 预览构建后的应用
npm run minify 压缩代码文件
npm run restore 恢复压缩前的代码
💡 提示：开发服务器默认运行在 http://localhost:5173，支持局域网访问。

onMessage.js - 接收消息处理

该文件负责接收来自前端界面的消息，并根据消息类型执行相应的3D场景操作。

// 主要消息类型处理 switch (event.data.cmd) { case "changeWeather": { // 天气切换 const param = event.data.param; core.ground.switchWeather({ type: param.type, level: param.level }); break; } case "changeSystem": { // 系统切换 core.changeSystem(event.data.param); break; } case "changeIndoor": { // 室内场景切换 core.changeIndoor(event.data.param); break; } }

支持的消息类型

消息类型 参数 功能描述
changeWeather {type, level} 切换天气效果（晴天、雨天、雪天等）
changeSystem systemName 切换3D子系统（地面系统、室内系统等）
changeIndoor buildingName 切换到指定室内场景

postMessage.js - 发送消息

该文件负责向父窗口发送消息，通知前端界面3D场景的状态变化。

// 发送加载完成消息 export const postOnLoaded = () => { window.parent.postMessage({ cmd: "onLoaded", }, "*"); }; // 发送首次加载消息 export const postFirstLoad = () => { window.parent.postMessage({ cmd: "firstLoad", }, "*"); };

发送的消息类型

消息类型 触发时机 功能描述
onLoaded 模型加载完成 通知前端3D模型已加载完成
firstLoad 首次初始化完成 通知前端3D系统已准备就绪
⚠️ 注意事项：
  • 消息处理采用异步方式，确保Store3D实例完全初始化后再处理消息
  • 使用动态导入避免循环依赖问题
  • 消息参数需要进行有效性验证

🧩 核心组件

天气系统

支持多种天气效果和日夜切换，包括：

  • SUNNY 晴天
  • RAIN 雨天
  • SNOW 雪天
  • DAY 白天
  • NIGHT 夜晚
  • SCIENCE 科幻风格

场景切换

支持室内外场景无缝切换：

  • 室外建筑群展示
  • 室内楼层切换
  • 相机动画过渡
  • 场景状态保持

交互控制

丰富的用户交互功能：

  • 鼠标控制相机视角
  • 键盘漫游控制
  • 点击选择对象
  • 缩放和平移

Store3D 核心API

changeSystem(systemName) string void 切换子系统
changeIndoor(buildingName) string void 切换到室内场景

🚀 部署说明

构建配置

项目使用Vite作为构建工具，配置文件为vite.config.js：

  • 输出目录：docs/
  • 支持静态资源复制
  • 自动生成模型列表
  • 代码压缩和优化

部署步骤

# 1. 构建生产版本 npm run build # 2. 部署docs目录到Web服务器 # 支持静态文件服务器，如Nginx、Apache等 # 3. 配置WebSocket连接 # 修改public/config.js中的WebSocket地址

环境配置

// public/config.js window.configs = { websocket: "ws://your-server:9999/gis/gis/websocket/client", floorToName: { // 楼层配置 } };
💡 部署建议：
  • 使用HTTPS协议确保WebSocket连接安全
  • 配置适当的缓存策略优化加载性能
  • 确保WebSocket服务器可访问
  • 定期更新3D模型和纹理资源
